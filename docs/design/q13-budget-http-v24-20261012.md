not_verified. It binds a nonce, original version/action, immutable flattened owned source,

server-selected queries/POST endpoint/body and complete ordered cursor chains are retained.
Each response commits raw bytes plus allowlisted request-id/status and request/body digest;
no credentials or arbitrary headers enter the packet. It is a non-atomic settings read.

Strict selected-field decoding retains explicit missing-vs-zero/false. Only documented
queryResourceConsumption and totalResultsCount are additionally accepted and validated;

foreign resources, broken joins, loops, count mismatch and nonterminal queries refuse.

monotonic duration, original clock and credential expiry limits apply; original owned
source/privacy revalidation brackets IO and occurs after failures. Credentials are excluded
from serialization/repr; failures are fixed safe strings and private HTTP logging is scoped.
