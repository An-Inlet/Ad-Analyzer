# Exact own-successor continuation

Actual component acceptance reproduced a self-invalidation: real reported
comparison→candidate→separate reviewed repeat plan→approved run transfers the
held reservation, after which strict original-head comparison rejects its own
first claim. Baseline `/tmp/inlet-rule-auto-actual.log` records that failure.

Keep normal selection/result/report reads strictly current-head. Add a server-only
optional forward review context, propagated solely by candidate review/admission
guards. It is never an API request field or general historical-read mode. Before
allowing the original anchor through its own transfer, prove the composite owned
review→candidate link→result→job→original-session/work/decision/opportunity;
parse/check every document commitment, and prove the exact direct immutable
reservation replacement from that original run to the current held successor
whose review is precisely this linked review. Same workspace, actor/session,
environment, ledger, native account/target/owner and exact intended action remain
mandatory. No arbitrary descendant or second successor is accepted.

The only later attempt that may be excluded as an intervention is that exact
successor's one original, still-claimed (`dispatching`), not-yet-emitting step, with exact request /
plan / fence lineage and no response or receipt. Unknown/emitting/completed or
unrelated later originals are not forward exceptions. Original latest receipt,
source, privacy, goal, session, policy, comparison/capsules and expiry checks stay
unchanged. New claims, replay, hold release and historical financial settlement
are neither inferred nor authorized by this context. Normal receipt reconciliation
keeps its independent existing historical path.

The continuation only prevents the exact already-approved successor's bookkeeping
from invalidating its own frozen evidence. Existing reviewed replacement proof,
financial admission, cumulative ledger limits and final original-session guards
still execute independently. Tests must cover manual and explicit automatic flow,
unrelated context, original-receipt drift, revoked session, erased capsule and
unknown successor with the same original fence/retained exposure.
