# Initial Preview Review Lifecycle And Export

The initial-preview review link is protected execution provenance. Its workspace
scope and explicit scalar export fields are registered separately from the derived
observation/calibration/preview graph. Export includes the original protected
review marker and origin, minimal commitments and the nullable owned pointer.
The original session digest is internal and excluded. No arbitrary JSON, aggregate
amount copies or provider payloads are added by this projection.

A strict typed serializer validates hash/reference shapes, environment, original
interval and all-present/all-null owned pointer. Invalid rows make the export
section incomplete rather than emitting an unvalidated payload. A non-null pointer
is historical linkage, not a claim of current execution authority. Erasure can
null it while keeping the original commitments unchanged.

Independent integration checks use the actual Meta mocked-HTTP preview and the
explicit contract-test qualification/exposure fixture. Metadata-created schemas
and actual migration0076 are both exercised on SQLite and PostgreSQL. The tests
verify original-origin immutability, protected-review deletion denial, all-null
FK retraction, no reattachment, missing-child retry denial, workspace-scoped export
and no session export. A cached ordinary marker loaded before another transaction
sets protected provenance cannot bypass the refreshed forward guard.

Migration downgrade succeeds before protected records exist and refuses after a
marked review remains, including after child deletion. Semantic privacy erasure
removes the derived preview while retaining the protected review and commitments.
The separate backend owner verifies attempted dispatch/reconciliation/settlement;
these tests do not manufacture or claim live financial settlement evidence.

No retention-policy exception, new spending authority, live factory, provider
request, remote repository write or deployment is enabled by this package.
