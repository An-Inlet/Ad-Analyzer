# Session Automation Customer Consumer

The Existing Campaigns page keeps its manual exact-review flow and separately
consumes the frozen session automation ports at332d7fc. Customers choose a readable
server-projected consented mandate and registered policy. The browser sends only
those exact references after explicit acknowledgement; it never supplies evidence,
policy numbers, financial proofs or an authority variant.

The readonly mandate summary displays the overall limit, currency, exact period,
consented revision and environment. Contract tests are labeled offline. Unavailable
capabilities do not become configured merely because the page exists. Original
session lifetime and the inability to recall an already sent change are explicit.

Start and Stop are never automatically replayed. An uncertain mutation disables
further automatic changes until the customer reads owned history and selects a
saved run. Status recovery uses GET only. Start is disabled while the bounded
history contains a nonterminal run. Stop remains available for a known owned run
when execution capabilities are disabled, subject to current server authorization.

The module shares the existing session, origin/CSRF, workspace epoch and stale
response guards. Workspace A→B→A, changed selections, logout, role denial and
in-flight session-cookie replacement cannot restore prior actionable status.
All labels/messages are textContent; no browser storage or secrets are introduced.

## Validation Boundary

Real HTTPS browser tests use actual sign-in/workspace/manual optimization APIs on
SQLite and disposable PostgreSQL. The automation-only browser scenario currently
uses controlled frozen JSON responses to test delayed/lost-response and session
cleanup behavior; it does not claim actual automation backend execution. The
scheduler owner is implementing those routes and persistence separately. Actual
backend integration qualification is still required when that head freezes.

Default production runtime/policy/evidence remain disabled. This UI supplies no
spending qualification or logout-independent delegation.
